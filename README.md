# optPOScenter: быстрый каталог и ЗИП

Приватный репозиторий Jeronimo701. Доступ — владельцу и приглашённым пользователям GitHub. Перенесён из Secret Gist вместе с исходной историей Git; прежний Gist закрывается удалением после проверки переноса.

## Установка и обновление вручную

Войдите в GitHub под аккаунтом с доступом к этому репозиторию. Откройте `Optposcenter_catalog_plus.user.js`, скачайте файл через Download raw file и установите его в Tampermonkey. Для каждого обновления повторите эти действия. Не добавляйте пароли или токены GitHub в код и адреса скрипта.

Текущая версия: **0.2.7** (предыдущая: 0.2.6). Изменена только публикационная часть заголовка: версия, адрес домашней страницы и отключение автоматической проверки обновлений через `@updateURL none`. Тело скрипта, @name и @namespace сохранены. Автообновления отменены по прямому выбору владельца. Ранее установленную копию нужно один раз заменить этим файлом.

Собственные условия — LICENSE.txt и LICENSE-SCOPE.md. Историческое описание с прежними адресами сохранено отдельно в README-GIST-HISTORICAL.md; первоначальный текст также доступен в истории Git. Метаданные переноса — MIGRATION.json.
